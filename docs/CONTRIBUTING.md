# قواعد المساهمة

1. ممنوع الرفع المباشر على `main` أو `dev`.
2. كل فريق يشتغل في مجلده وعلى فرعه (`feat/<team>`).
3. قبل أي push: `git pull origin feat/<team>`.
4. رسالة الـ commit: `type: وصف` (feat / fix / docs / chore).
5. لما تخلص جزء: افتح Pull Request من فرع الفريق إلى `dev`، والقائد يراجع.
6. ممنوع رفع: مفاتيح، Tokens، ملفات `.env`، بيانات، موديلات كبيرة.
7. كل تاسك = Issue على GitHub Project Board.
